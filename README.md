# Disney Watch Party (Hunty)

Free Chrome extension that keeps two people's Disney+ playback in sync, with a chat box. Peer-to-peer (PeerJS), no server, no account.

## Install (both computers)
1. Unzip the folder.
2. In Chrome go to chrome://extensions and turn on Developer mode (top right).
3. Click "Load unpacked" and pick this folder.

## Use
1. Both log in to Disney+ (same account is fine, Disney+ allows 4 streams).
2. One person opens the show and clicks "Start a party" in the box at the bottom right. Send the 4-letter code.
3. The other person clicks "Join a party" with the code. The host's show opens on their side automatically.
4. Play, pause, skip, and chat. Either person can control it.

Files: manifest.json, content.js (sync + chat), panel.css (the box), peerjs.min.js (PeerJS 1.5.4, MIT).
